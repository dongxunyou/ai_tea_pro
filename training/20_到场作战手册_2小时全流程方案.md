# 到场作战手册 · 能力测评 2 小时全流程方案

> 使用方式：到场后**从第 0 步开始，一步一步照着做**，不要跳步。
> 已核实官方规则（第九届 2026 总决赛能力测评通知，socchina.net 官网）：
> - 现场实操考核，**限时 2 小时**，专家现场验收 + 录屏；
> - **禁止带通讯设备，电脑全程断网，禁止任何 AI 辅助（含本地 AI）** → 代码必须装在脑子里和自己的工程里；
> - 现场只提供桌椅和 220V 电源，开发板/工具/线材全部自备，**建议带备用开发板**；
> - 允许用面包板、独立模块外扩（板载资源不够就外接，不算违规）。

### 模板工程（考前做好，考场的起跑线）

用官方 `01_LED` 例程的 `.ioc` 为基础，CubeMX 里 **Toolchain 选 CMake** 重新生成，然后在 `.ioc` 里**预先开好这些外设**（考场不公布题目，这些是官方范围里明示的，开了不亏）：

| 外设 | 配置 | 对应引脚 |
|---|---|---|
| GPIO 输出 ×5 | LED0、LED1、蜂鸣器、外接 LED×2 | PG10 / PE10 / PD3 / 自选 2 个空脚 |
| GPIO 输入 ×4 | 4 个按键，上拉（WKUP 下拉） | PC13 / PC6 / PD1 / PG11 |
| GPIO EXTI ×4 | 同上 4 键，KEY0/1/2 下降沿，WKUP 上升沿，开 NVIC | 同上 |
| USART1 | 异步 115200-8-N-1，开 RX 中断 | PE5 / PE6 |
| TIM6 | 基本定时器，1ms 或 100ms 中断，开 NVIC | — |
| TIM3 CH1 | PWM 输出 | PC6 |
| ADC1_IN15 | 单通道轮询 | PF6 |
| I2C4 | 标准模式 100k（EEPROM） | PE13 / PE14 |

模板工程里写好的内容：printf 重定向、按键扫描函数、LED/蜂鸣器宏、OLED 驱动文件（从官方 BSP 搬好编译通过）。**应用逻辑一行不写——那是考场上现场干的事。**

> 注意分寸：底层驱动提前备好是官方默许的（其他赛题通知里明确写了"底层驱动程序可提前准备，现场主要进行应用程序设计"）；但应用功能必须现场写，验收专家会看着你操作。

## 第 0 步 · 进场后 0~10 分钟：环境自检（不做完不写代码！）

1. 接好板子、ST-LINK、串口线，开串口助手选好 COM 口（115200）。
2. 打开 CubeProgrammer → Connect（确认 ST-LINK 通讯正常）。
3. **把模板工程原样编译 + 烧录一次**：
   ```powershell
   cmake --build --preset Debug
   ```
   CubeProgrammer 烧 `Appli/build/*.elf` → 复位 → 板子有反应（模板里留个 LED 心跳）。
4. 有问题立即换 USB 口 / 换线 / **换备用板**。10 分钟内必须解决，解决不了叫现场工作人员。

> 铁律：**不验证烧录链路就写代码 = 自杀。**

---

## 第 1 步 · 10~30 分钟：保底及格分（先拿"流水灯"级别的保底分）

不管题目是什么，先花 20 分钟把这套**保底程序**写完烧进去——听说上届写个流水灯就及格，这套远超流水灯：

```c
/* ===== 保底程序：4灯流水 + 按键响应 + 蜂鸣器 + 串口心跳 ===== */
/* 引脚宏（背！） */
#define LED0(x)  HAL_GPIO_WritePin(GPIOG, GPIO_PIN_10, (x)?GPIO_PIN_SET:GPIO_PIN_RESET)
#define LED1(x)  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_10, (x)?GPIO_PIN_SET:GPIO_PIN_RESET)
#define BEEP(x)  HAL_GPIO_WritePin(GPIOD, GPIO_PIN_3,  (x)?GPIO_PIN_SET:GPIO_PIN_RESET)

uint32_t tick = 0;          /* 软件计时 */
uint8_t  key  = 0;

while (1)
{
    /* --- 每 50ms 一圈 --- */
    HAL_Delay(50);
    tick += 50;

    /* --- 流水灯：每 200ms 换一个灯 --- */
    if (tick % 200 == 0)
    {
        static uint8_t pos = 0;
        LED0(pos == 0); LED1(pos == 1);
        /* 外接 LED2/LED3 同样写 */
        pos = (pos + 1) % 4;
    }

    /* --- 按键扫描（消抖） --- */
    key = key_scan();             /* 模板里已写好，参考官方 key.c */
    if (key == 1) { BEEP(1); HAL_Delay(100); BEEP(0); printf("KEY0\r\n"); }
    if (key == 2) { LED0_TOGGLE(); }
    /* ... 其余按键 ... */

    /* --- 串口心跳：每秒打印一次 --- */
    if (tick % 1000 == 0) printf("RUNNING %lu\r\n", tick/1000);
}
```

**烧录验证 → 功能正常 → 立刻把 hex/elf 复制一份改名 `backup_v1.elf`。**
这 20 分钟结束，你已经超过"流水灯及格线"。后面每完成一项功能，存一个 `backup_vN.elf`。

## 第 2 步 · 30~100 分钟：按题目逐个击破（70 分钟主攻）

拿到题目后先花 **3 分钟读题 + 拆任务**：把题目要求拆成一行一行的小功能，按"会做/分值高"排序，**做一项烧一项验一项**。

### 题型 → 解法速查表（官方范围内就这些考法）

| 题目关键词 | 对应做法 | 参考官方例程 | 预计耗时 |
|---|---|---|---|
| 流水灯 / LED 闪烁 / 指定频率闪 | GPIO + HAL_Delay 或定时器 | 01_LED | 5 min |
| 蜂鸣器响 / 指定频率鸣叫 | 有源蜂鸣器：GPIO 通断；指定频率：TIM3 PWM 接蜂鸣器 | 02_Buzzer / 092_PWM | 10 min |
| 按键控制 XX / 按键计数 | 轮询 + 消抖（模板 key_scan） | 03_Button | 10 min |
| 外部中断 / 中断计数 | 按键改 EXTI，中断置标志，主循环处理 | 04_Button_EXTI | 15 min |
| 串口打印 / 上报数据 | printf 重定向（模板已有） | 05_Serial | 5 min |
| 串口命令控制 | 中断收 1 字节存 buffer，收到 \n 置标志，strstr 解析 | 05_Serial (uart.c) | 20 min |
| PWM / 呼吸灯 / 调光 | TIM3_CH1，`__HAL_TIM_SET_COMPARE` 改占空比 | 092_PWM | 15 min |
| 定时 / 每 N 秒做 XX | TIM6 中断里置标志 | 08_Basic_Timer | 10 min |
| 电压 / 电位器 / 模拟量 / 光敏 | ADC1_IN15(PF6) 轮询读，×3.3/4095 换算 | 20_ADC | 15 min |
| OLED 显示数字/文字 | 模板 OLED 驱动，`oled_show_string/num` | 12_OLED | 15 min |
| 掉电保存 / 参数存储 | I2C4 EEPROM 读写（地址 0x50） | 23_EEPROM | 20 min |

### 考场编码 5 条军规

1. **一次只改一个功能**，改完立即编译烧录验证，不攒着。
2. 每个版本存备份 hex（`backup_v2、v3...`），改崩了 30 秒刷回上一版。
3. 中断函数里**只置标志位**，绝不 printf / HAL_Delay。
4. 卡壳超过 **10 分钟**：放弃该小项，做下一项，最后有时间再回来。
5. 剩 30 分钟时**停止开新功能**，进入收尾（第 3 步）。

---

## 第 3 步 · 100~120 分钟：收尾验收（别死在最后一步）

1. **整体回归测试（10 min）**：按题目逐条对着测，每测过一条在题纸上打勾。
2. **稳定版烧录（5 min）**：把最终 elf 重新烧录、复位、断电重上电各验证一次（专家看的就是上电后的状态）。
3. **演示准备（5 min）**：想清楚待会怎么演示：先按哪个键、串口发什么、指哪个灯。**演示顺序 = 题目顺序**，专家好对照。
4. 录屏/验收时边操作边说一句这是什么功能（"这是按键中断计数，按一下加一"），显得是你自己写的。
5. 验收表签字前确认所有要求项都演示过了，**没演示 = 没分**。

## 应急方案（背下来，考场不慌）

| 事故 | 处理 |
|---|---|
| CubeProgrammer 连不上 | 换 USB 口 → 换线 → 重启软件 → 换备用 ST-LINK |
| 编译突然报一堆错 | 八成是 CubeMX 重新生成覆盖了 USER CODE 区外的代码 → 用 backup 恢复 |
| 板子完全没反应 | 按复位 → 重烧 → 烧 backup_v1 → 还不行烧官方 `01_LED appli.hex` 区分软硬件问题 |
| 手滑 Mass Erase 变砖 | CubeProgrammer 烧官方 `fsbl.hex`（0x70000000 起始，按平时流程），再烧 Appli |
| 串口没字 | TX/RX 接反 / 波特率 / 忘了重新开接收中断 |
| 电脑死机 | 重启，工程在本地磁盘，hex 备份都在，10 分钟能恢复 |

## 必背代码块（考前默写到 3 分钟能敲完一段）

### ① printf 重定向

```c
int fputc(int ch, FILE *f)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
    return ch;
}
```

### ② 按键扫描（消抖 + 松手检测）

```c
uint8_t key_scan(void)
{
    if (KEY0==0 || KEY1==0 || KEY2==0 || WKUP==1)   /* 有键按下 */
    {
        HAL_Delay(10);                              /* 消抖 */
        if (KEY0==0) { while(KEY0==0); return 1; }  /* 等松手，返回键值 */
        if (KEY1==0) { while(KEY1==0); return 2; }
        if (KEY2==0) { while(KEY2==0); return 3; }
        if (WKUP==1) { while(WKUP==1); return 4; }
    }
    return 0;
}
```

### ③ EXTI 中断（中断里只置标志）

```c
uint8_t key0_flag = 0;
void HAL_GPIO_EXTI_Falling_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_6) key0_flag = 1;      /* PC6=KEY0 */
}
/* 主循环：if (key0_flag) { key0_flag=0; ...干活... } */
```

### ④ 串口中断接收（一次 1 字节，\n 结尾）

```c
uint8_t rx_byte, rx_buf[64], rx_len = 0, rx_done = 0;
/* 初始化后开第一次接收 */ HAL_UART_Receive_IT(&huart1, &rx_byte, 1);
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *h)
{
    if (rx_byte == '\n') { rx_buf[rx_len]=0; rx_done=1; rx_len=0; }
    else if (rx_len < 63) rx_buf[rx_len++] = rx_byte;
    HAL_UART_Receive_IT(&huart1, &rx_byte, 1);      /* 必须重开！ */
}
/* 主循环：if (rx_done) { rx_done=0; if(strstr(rx_buf,"LED1 ON"))... } */
```

### ⑤ PWM 启动与调占空比

```c
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);   /* 0~ARR */
/* 频率 = 定时器时钟 / ((PSC+1)*(ARR+1))，>=100Hz 人眼不闪 */
```

### ⑥ 定时器中断

```c
HAL_TIM_Base_Start_IT(&htim6);
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *h)
{
    if (h->Instance == TIM6) tim6_flag = 1;
}
```

### ⑦ ADC 读电压

```c
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 10);
uint32_t raw = HAL_ADC_GetValue(&hadc1);          /* 0~4095 */
float volt = raw * 3.3f / 4095.0f;
HAL_ADC_Stop(&hadc1);
```
