# 模拟题库 · 蓝桥杯国赛风格 4 套（难 → 易）

> 蓝桥杯嵌入式国赛/省赛的经典套路 = **"一个综合应用 + 传感器采集 + 显示 + 按键设置 + 串口通信 + EEPROM 保存"**，与本赛能力测评范围高度重合。
> 使用规则：每套限时 **2 小时**，先自己拆题写提纲再动手；做完对照《思路》复盘；卡壳超 10 分钟先跳过。
> 四道都做一遍，基本覆盖考场上能遇到的所有题型。

---

# 第 1 套（难）★ 智能温度监测报警仪

> 原型：蓝桥杯国赛"温度监控系统"。用电位器（ADC）模拟温度传感器，综合性最强，啃下这套 = 考场上 80% 的点都会了。

## 功能要求（100 分）

### 基础（55 分）
1. **采集（15）**：ADC(PF6) 采集电位器电压，0~3.3V 映射为 0.0~100.0°C，OLED 第一行显示 `TEMP: 36.5C`（保留 1 位小数）。
2. **报警（15）**：温度超过上限（默认 50.0°C）时：蜂鸣器响（200ms 响 / 800ms 停循环）、LED0 快闪（100ms 翻转）；低于上限自动恢复。
3. **按键设置（15）**：KEY1 上限 +1°C，KEY2 上限 −1°C（范围 20~80），OLED 第二行显示 `TH: 50.0`。
4. **串口上报（10）**：每秒串口打印一次：`TEMP:36.5,TH:50.0,ALARM:0`。

### 提高（30 分）
5. **报警计数（10）**：每次"从正常变为超限"计 1 次，OLED 第三行显示 `CNT: 3`。
6. **EEPROM 保存（10）**：上限值和报警次数掉电保存，上电自动恢复（I2C4，地址 0x50）。
7. **串口命令（10）**：电脑可发 `SET TH 65.0`（设上限）、`GET`（回传当前全部状态）、`CLR`（清零计数），均回 `OK`，非法命令回 `ERR`。

### 挑战（15 分）
8. **PWM 风扇（15）**：TIM3_CH1(PC6) 输出 1kHz PWM 模拟风扇（外接 LED 观察亮度）：温度 30°C 以下占空比 0%，30~80°C 线性升到 100%，80°C 以上 100%。（PC6 与 KEY0 复用，本题 KEY0 禁用）

## 解题思路（做完再看）

**拆模块（按这个顺序做，每步烧录验证）：**

```
ADC 采集+OLED 显示(20min) → 报警逻辑(15min) → 按键调上限(10min)
→ 串口上报+命令(25min) → EEPROM 保存(20min) → PWM 风扇(15min) → 回归测试(15min)
```

**关键设计：**
1. 主循环用 **50ms 节拍**（HAL_Delay(50) + 软件计数器分频：显示 200ms、上报 1000ms、蜂鸣器节拍）——不要写一长串 HAL_Delay，否则按键会卡。
2. 温度换算：`temp = adc_raw * 100.0f / 4095.0f;`（电位器满量程就对应 100°C，别把 3.3V 再乘进去）。float 打印用 `printf("%.1f", temp)`；若不输出小数，在 `printf` 里用 `(int)temp` 和 `(int)(temp*10)%10` 拆开打。
3. 报警计数要的是**上升沿**：用 `last_alarm` 变量记录上次状态，`now==1 && last==0` 时才 `cnt++`。
4. EEPROM **写之前不用擦除**（它不是 Flash），但写一个字节后要 `HAL_Delay(5)` 等写周期完成；上电读出来先判断合法性（如 >150 视为空片，用默认值 50.0）——这是 EEPROM 题的经典给分点。
5. 串口命令解析：`sscanf(rx_buf, "SET TH %f", &th)` 比手工拆字符串快 10 倍。

**坑预警：** float 变量存 EEPROM 要拆字节（用 `uint8_t*` 强转或 union，4 字节）；OLED 刷新别太频繁（200ms 一次够了，刷屏很耗时）。

# 第 2 套（较难）★ 多功能信号测量仪

> 原型：蓝桥杯"电压/频率测量与 PWM 输出"类题。考察定时器/PWM/ADC/串口，对"参数可调"要求高。

## 功能要求（100 分）

### 基础（55 分）
1. **PWM 输出（20）**：TIM3_CH1(PC6) 输出方波，频率 1kHz、占空比 50%，外接 LED 可见（半亮）。
2. **参数按键可调（20）**：KEY1 循环切换频率（1k/2k/4kHz），KEY2 循环切换占空比（10/30/50/70/90%），OLED 显示 `F:1000Hz D:50%`。
3. **ADC 测量（15）**：采集 PF6 电压，OLED 第二行显示 `V:1.65V`，每秒串口打印一次。

### 提高（30 分）
4. **状态指示（10）**：占空比 >60% 时 LED1 亮，否则灭；电压 >2.0V 时 LED0 亮 + 蜂鸣器间歇报警。
5. **串口命令（10）**：`F 4000`（设频率）、`D 80`（设占空比%）、`GET`（回传全部参数），回 `OK`/`ERR`。
6. **掉电保存（10）**：当前频率、占空比保存 EEPROM，上电恢复。

### 挑战（15 分）
7. **简易示波器（15）**：OLED 上用竖线柱（bar）实时显示最近 16 次 ADC 采样值（每次采样画一柱，高度∝电压），500ms 左移一格。

## 解题思路

**顺序：** PWM 输出(15min) → 按键调参(15min) → ADC+显示(15min) → 串口(20min) → EEPROM(15min) → 示波器(20min) → 测试(20min)

**关键设计：**
1. **改频率的规范做法**：只改 ARR，不重初始化定时器——
   `__HAL_TIM_SET_AUTORELOAD(&htim3, arr); __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, arr*duty/100);`
   预计算：定时器时钟 200MHz，PSC 设 199（→1MHz 计数），1kHz 对应 ARR=999，频率 f 对应 `arr = 1000000/f - 1`。
2. 参数表用数组 + 下标循环：`freq_tab[]={1000,2000,4000}; idx=(idx+1)%3;`
3. 简易示波器：定义 `uint8_t hist[16]` 存最近 16 次采样的高度（0~31 像素），每 500ms 数组整体左移一格、末尾填新值，然后 `for(i=0;i<16;i++) oled_draw_vline(i*8, 32-hist[i], hist[i]);`（用官方 oled.c 的画点函数包一层竖线即可）。
4. 串口设频率后要**验证范围**（100~10000Hz 才执行，否则回 ERR）——评分细则爱考这个。

**坑预警：** 改完 ARR 必须同步改 CCR（否则占空比飘了）；OLED 全屏刷新慢，只重画变化的区域。

# 第 3 套（中等）★ 计时收费终端

> 原型：蓝桥杯"停车计费系统"。核心是**状态机**，逻辑比外设难，练思维。

## 功能要求（100 分）

### 基础（55 分）
1. **状态机（25）**：三个状态：空闲(IDLE) → 计时中(RUN) → 结算(STOP)。
   - IDLE：OLED 显示 `READY`，LED0 慢闪（1s）；
   - KEY0 短按：进入 RUN，开始计时；
   - RUN：OLED 显示已用时间 `T:00:23`（分:秒），LED1 亮；
   - KEY0 再按：进入 STOP，停止计时，显示费用 `FEE:6.0`；
   - KEY0 再按：回 IDLE，清零。
2. **计费规则（15）**：费率 0.5 元/分钟（不足 1 分钟按 1 分钟计，即 65 秒 = 2 分钟 = 1.0 元）。
3. **蜂鸣器提示（15）**：进入 RUN 响 100ms，结算时响两声（100ms 间隔 100ms）。

### 提高（30 分）
4. **费率可调（10）**：KEY1 加 0.5、KEY2 减 0.5（范围 0.5~5.0），IDLE 状态下 OLED 第二行显示 `RATE:0.5`。
5. **累计收入（10）**：每次结算把费用累加到总收入，WKUP 长按 2 秒查询总收入（显示 3 秒）。
6. **掉电保存（10）**：费率和累计收入存 EEPROM，上电恢复。

### 挑战（15 分）
7. **串口记录（15）**：每次结算串口打印一条流水：`NO.5,T:65s,FEE:1.0,SUM:12.5`；电脑发 `SUM` 回传总收入，`CLR` 清零总收入。

## 解题思路

**顺序：** 状态机骨架+OLED(30min) → 计时+计费(15min) → 蜂鸣器(5min) → 费率/总收入(15min) → EEPROM(15min) → 串口(20min) → 测试(20min)

**关键设计：**
1. 状态机写法（背下来，万能模板）：
   ```c
   typedef enum { IDLE, RUN, STOP } state_t;
   state_t st = IDLE;
   while (1) {
       key = key_scan();
       switch (st) {
           case IDLE: if (key==1) { st=RUN; t_start=HAL_GetTick(); } break;
           case RUN:  if (key==1) { st=STOP; t_end=HAL_GetTick(); } break;
           case STOP: if (key==1) { st=IDLE; } break;
       }
       /* 显示/计时按 st 分别处理 */
   }
   ```
2. 计时用 `HAL_GetTick() - t_start`（**不要数循环次数**）；分:秒显示：`printf("%02d:%02d", sec/60, sec%60)`。
3. 不足 1 分钟按 1 分钟：`minutes = (sec + 59) / 60;`
4. 长按检测：按下时记录时间，循环里判断"还按着 && 超过 2000ms"触发一次。

**坑预警：** RUN 状态下别让 OLED 每秒全屏刷（只刷时间那行）；结算费用只在进入 STOP 时算**一次**（放状态切换的那一瞬间，别放循环里一直算）。

# 第 4 套（易）★ 电子密码锁

> 原型：蓝桥杯省赛"电子锁/密码锁"。入门级，考核当天若题目简单就长这样。

## 功能要求（100 分）

### 基础（60 分）
1. **密码输入（25）**：初始密码 `1234`。KEY0/1/2 分别输入数字 1/2/3，WKUP 当"确认"键；按一下 OLED 上多显示一个 `*`。
2. **验证（20）**：输满 4 位按确认：密码对 → LED0 亮 3 秒 + 蜂鸣器响 100ms + OLED 显示 `OPEN`；密码错 → 蜂鸣器响 1 秒 + 显示 `ERROR`，3 秒后清空重来。
3. **输错锁定（15）**：连续错 3 次，锁定 30 秒（OLED 显示倒计时 `LOCK:27`），期间按键无效，LED1 快闪。

### 提高（25 分）
4. **修改密码（15）**：开锁状态下 KEY1 长按 2 秒进入改密模式，输入新 4 位密码（4~8 位数字都行），按确认保存。
5. **掉电保存（10）**：新密码存 EEPROM，上电读取（空片时用默认 1234）。

### 挑战（15 分）
6. **串口后台（15）**：电脑发 `OPEN 1234` 可直接开锁（密码对回 `OK`，错回 `ERR`）；开锁状态下发 `LOCK` 立即锁定。

## 解题思路

**顺序：** 按键输入+显示(20min) → 验证逻辑(15min) → 锁定(10min) → 改密+EEPROM(20min) → 串口(15min) → 测试(15min)

**关键设计：**
1. 输入缓冲：`char in[9]; uint8_t len=0;` 按键把 '1'/'2'/'3' 追加进去，确认时 `strcmp(in, password)`。
2. 密码存储：EEPROM 第 0 字节存长度，1~8 字节存字符；上电读长度，若 `len<4 || len>8` 判定空片，写默认密码。
3. 锁定倒计时也是状态机的一个状态（`LOCKED`），用 `HAL_GetTick()` 算剩余秒数，**别用 HAL_Delay(30000) 死等**（那样串口也死了）。
4. 显示 `*` 的数量 = `len`，按退格（KEY2 长按）可 `len--`（选做加分细节）。

**坑预警：** `strcmp` 比较前确认 `in` 有 `\0` 结尾；EEPROM 写完读回校验一次再算成功。
