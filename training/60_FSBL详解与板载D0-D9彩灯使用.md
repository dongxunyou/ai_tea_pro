# FSBL 详解 + 板载 D0~D9 彩灯使用 + 外接 LED 实锤

> 回答你 4 个问题：①FSBL 是干嘛的；②官方 LED 例程的 FSBL 和你们板子里烧的 AI 例程 FSBL 有啥不一样；③官方各例程的 FSBL 都有啥不同；④板子上 D0~D3 怎么开（顺便：外接 LED 的引脚已从官方 IO 分配表实锤）。

---

## 1. FSBL 是干嘛的（傻瓜版）

N647 **内部没有 Flash**，程序全存在外部 Flash 芯片里。芯片一上电，内置的一小段只读程序（BootROM）先把 **FSBL**（First Stage Boot Loader，第一阶段引导程序）从外部 Flash 读出来运行。FSBL 干 4 件事：

1. **配时钟**（CPU、总线、NPU 等，详见《50》A 章）；
2. **配 XSPI 接口**，把外部 Flash 映射成"内存"，让 CPU 能像读内存一样执行里面的代码；
3. **配外部 RAM**（板上的 W958D8NBYA5I HyperRAM，AI 工程要用来放模型和图像）；
4. **跳转**到我们的应用程序（Appli）开始跑。

所以：**FSBL 烧一次就不用管了，平时只烧 Appli。全片擦除 = 把 FSBL 也擦了 = 变砖**（用官方 `fsbl.hex` 救回）。

## 2. 官方 LED 例程 FSBL vs 你们烧的 AI 例程 FSBL（实测逐行 diff）

两个 FSBL 都拿到源码做了逐行对比，**差异 32 行，全部在时钟配置，XSPI/Flash/RAM/启动流程完全一样**：

| | 通用 FSBL（LED 等例程共用） | AI 例程 FSBL（992 等，你们板子里的） |
|---|---|---|
| PLL1 | 64/4×75 = 1200MHz | 64/2×25 = 800MHz |
| CPU 主频 | **600MHz**（IC1÷2） | **800MHz**（IC1÷1，满血） |
| PLL2 | 关 | 开，1000MHz（给 NPU） |
| PLL3 | 关 | 开，1600/800MHz（NPU/显示相关） |
| Flash/RAM 配置 | 相同 | 相同 |
| 跳转方式 | 相同 | 相同 |

**结论：AI 版 FSBL = 超频版**（CPU 拉到 800MHz + NPU 时钟拉满，因为跑神经网络算力饥渴）。对你们的影响：
- 跑 GPIO/串口/定时器这些基础功能，**两个 FSBL 没有任何区别**，不用换；
- 定时器 400MHz、总线 200MHz 的结论两个版本都成立（PSC=399 不变）；
- 建议：**板子里现在是哪个 FSBL 就一直用着，别混刷**。

## 3. 官方各例程的 FSBL 都有什么不同？

**基本都一样。** 整个例程包 60+ 个实验（LED、按键、串口、定时器、OLED、ADC、EEPROM……）共用同一个 FSBL：`Software_Package\FSBL\MX25UM25645G_W958D8NBYA5I_Example`。
唯一的例外就是 `99_Applications` 里的 AI 例程（992 图像分类等）自带了上面的"超频版" FSBL。

> 举一反三：这就是为什么官方每个例程的 Appli 里都没有 SystemClock_Config——时钟全在 FSBL 里，换例程不用换 FSBL。

## 4. 板子上 D0~D9 是什么？怎么点亮 D0~D3？

### 4.1 先认清它们

照片里那一排 D0~D9 **不是普通 LED**，是 **10 颗 WS2812 全彩 RGB 灯珠**（原理图 RGBLED 部分实锤）：
- 串联菊花链，**数据脚 = PF1**（丝印 RGB_LED，经 1K 电阻）；
- 每颗灯 24bit 颜色（GRB），**不能像普通 LED 那样 WritePin 高低电平直接点**，必须用 WS2812 时序协议驱动；
- 官方驱动在 `Drivers\BSP\WS2812B\`（TIM4_CH3 + DMA 输出精确时序），例程在 `Projects\34_WS2812B\`（341_DMA 和 342_IO 两个版本，都有现成 `Binary\appli.hex` 可直接烧录看流水灯效果）。

### 4.2 点亮 D0~D3（固定颜色，最简用法）

把官方 `WS2812B/ws2812b.c + ws2812b.h` 搬进模板工程（和其他 BSP 一样放 `Appli/User/BSP/`），CubeMX 里按例程 `341_WS2812B_DMA.ioc` 配好 TIM4_CH3(PF1) + DMA，然后：

```c
ws2812b_init();                          /* 初始化 */
ws2812b_write_color(0, 0xFF0000);        /* D0 = 红 */
ws2812b_write_color(1, 0x00FF00);        /* D1 = 绿 */
ws2812b_write_color(2, 0x0000FF);        /* D2 = 蓝 */
ws2812b_write_color(3, 0xFFFF00);        /* D3 = 黄 */
/* 想全灭：ws2812b_reset(); */
```

（灯珠编号 0~9 对应板上 D0~D9，颜色是 0xRRGGBB。）

### 4.3 考核"4 个 LED"到底用哪种？建议

| 方案 | 优点 | 缺点 | 建议 |
|---|---|---|---|
| LED0(PG10)+LED1(PE10)+外接 2 个 | 最简单、最稳，考官秒懂 | 要插 2 根杜邦线 | **首选** |
| LED0/LED1 + WS2812 当 2 个 | 不用外接 | 要搬 DMA 驱动，CubeMX 多配 TIM4+DMA，出错点多 | 练熟再用 |
| 4 个全用 WS2812 | 好看 | 考官可能认为你在回避 GPIO 输出考点 | 不推荐 |

> 折中：**保底用外接方案，WS2812 学会后当加分项**（"顺便展示一下板载 RGB 彩灯"）。

## 5. 外接 LED 引脚实锤（官方 IO 分配表已核实）

《40》文档里选的外接脚 PA3/PB14 已对照 `ATK-DNN647 IO引脚分配表.xlsx` 确认：

| 引脚 | 板上功能 | 排针引出 | 当外接 LED 脚是否安全 |
|---|---|---|---|
| **PA3** | LCD_BL（LCD 背光） | 是 | ✅ 安全（有 10K 下拉，推挽输出高电平点灯没影响） |
| **PB14** | DCMI_CAM_XCLK（摄像头时钟） | 是 | ✅ 安全（官方注明"摄像头未接入时，该 IO 完全独立"） |
| 备用 PF8 | LCD 接口 WR | 是 | LCD 不接时独立 |
| 备用 PG14 | 摄像头 PWDN | 是 | 摄像头不接时独立 |

接法：排针脚 → LED 正极（长脚）→ LED 负极 → 220Ω 电阻 → GND（板上排针有 GND）。高电平点亮。

> 注意：PA3 同时是 LCD 背光控制——如果考核当天还插着 RGB LCD，PA3 点灯会让 LCD 背光跟着闪。届时把 LCD 排线拔了，或换 PF8/PG14。
