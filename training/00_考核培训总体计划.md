## 0. 学习纪律（先读这个！）

1. **所有代码必须自己亲手敲一遍**，禁止复制粘贴。敲错了、编译报错了，才是真正学到东西的时候。
2. 每章都有"过关标准"，**做到了再进下一章**，不要跳。
3. 遇到报错先看各章末尾的《常见错误排查表》，解决不了再问。
4. 准备一个小本子（或一个 txt），把每次踩的坑记下来，考核前翻一遍。
5. 每天结束把今天敲的代码保存好（git commit 或复制备份）。

## 2. 开发板真实资源速查表（已从官方例程核实！）

### 2.1 芯片特点（只需要记住 3 句话）

1. STM32N647 是 Cortex-M55 内核，**内部没有 Flash**，程序存放在外部 Flash 芯片（MX25UM25645G）里。
2. 上电后先运行一小段叫 **FSBL** 的启动程序，它把外部 Flash 配置好，再跳转到我们的应用程序（Appli）。
3. 烧录铁律：**平时只烧 Appli，永远不点"全片擦除 / Mass Erase"**。万一真擦了，用官方 FSBL 恢复（见 3.4 节）。

### 2.2 板载资源引脚表（背下来！）

| 资源 | 引脚 | 电平逻辑 | 备注 |
|---|---|---|---|
| LED0 | PG10 | 高电平亮 | 板载 |
| LED1 | PE10 | 高电平亮 | 板载 |
| 蜂鸣器（有源） | PD3 | 高电平响 | 板载 |
| 按键 WKUP | PC13 | **按下 = 高电平** | 板载（注意与其他三个相反！） |
| 按键 KEY0 | PC6 | 按下 = 低电平 | 板载 |
| 按键 KEY1 | PD1 | 按下 = 低电平 | 板载 |
| 按键 KEY2 | PG11 | 按下 = 低电平 | 板载 |
| 串口 USART1 TX | PE5 | 115200-8-N-1 | 接电脑看打印 |
| 串口 USART1 RX | PE6 | 115200-8-N-1 | |
| PWM 输出 | PC6 | TIM3_CH1 | 与 KEY0 复用，练 PWM 时别按 KEY0 |
| ADC 输入 | PF6 | ADC1_INP15 | 接电位器/光敏（0~3.3V） |
| EEPROM | PE13/PE14 | I2C4_SCL/SDA，地址 0x50 | 板载 AT24 系列 |
| OLED（模块） | 见 2.3 | 软件 SPI | 插 OLED 模块时用 |

### 2.3 OLED 模块引脚（正点原子 OLED 模块，软件模拟 SPI）

| OLED 引脚 | 板子引脚 |
|---|---|
| RST | PQ2 |
| CS | PB8 |
| RS（即 DC） | PE13 |
| SCLK | PD7 |
| SDIN（即 MOSI） | PE6 |

> 注意：PE13/PE6 与 EEPROM/串口有复用关系，练 OLED 那一章时不要同时用串口1——实际接线以 OLED 模块插座的丝印为准。

### 2.4 关于"考核要 4 个 LED"

板载只有 2 个 LED，考核要求 4 个 → **用杜邦线外接 2 个 LED 模块**（或限流电阻+散灯），接任意空闲 GPIO（练习时在 CubeMX 里配置成输出即可）。这是考核的正常操作，别慌。

## 3. 官方例程包使用指南（宝藏，必读！）

### 3.1 它是什么 / 和我们的区别

官方例程在 `D:\BaiduNetdiskDownload\Software_Package`，是**正点原子针对这块板子写的 33+ 个裸机实验**。

和我们环境的区别只有 3 点：

| | 官方例程 | 我们 |
|---|---|---|
| IDE | STM32CubeIDE | VS Code + CMake |
| 操作系统 | **裸机（无 RTOS）** | 主项目带 FreeRTOS |
| 代码 | 标准 HAL 库 | 标准 HAL 库（**一模一样**） |

**结论：例程的 C 代码 100% 可以直接参考/手敲，与 IDE 无关。** 驱动代码在 `Software_Package\Drivers\BSP\` 下按模块分文件夹（LED、KEY、BEEP、UART、OLED、ADC、EEPROM、GTIM、BTIM、EXTI……），每个例程的 `Appli\Core\Src\main.c` 演示用法。

### 3.2 正确的使用姿势

1. 学哪一章，先打开对应例程的 `main.c` 和对应 BSP 驱动（如 `Drivers\BSP\KEY\key.c`）**通读一遍**；
2. 然后**合上书，在我们的工程里自己敲**（可以对照着敲，但不准复制粘贴）；
3. 搞不懂的寄存器/配置，双击打开该例程的 `.ioc` 文件，看 CubeMX 图形界面里是怎么配的。

### 3.3 每个例程都有"成品 hex"，可以先烧进去看效果

每个例程目录下有 `Binary\appli.hex`，**不用编译就能直接烧录**。用途：

- 学新外设前先烧官方成品，确认硬件/接线没问题（排除法：官方程序能跑 = 硬件没坏，问题在你的代码）；
- 知道"做对了是什么效果"。

### 3.4 烧录必备资源（都在例程包里）

| 文件 | 路径 | 用途 |
|---|---|---|
| 外部 Flash 烧录算法 | `External_Loader\MX25UM25645G_ATK-CNN647B\Binary\MX25UM25645G_ATK-CNN647B_ExtMemLoader.stldr` | CubeProgrammer 烧录时必须选它 |
| FSBL 成品 | `FSBL\MX25UM25645G_W958D8NBYA5I_Example\Binary\fsbl.hex` | 板子变砖（FSBL 被擦）时恢复用 |

> 第一次用 CubeProgrammer 时：把这个 `.stldr` 复制到 CubeProgrammer 安装目录的 `ExternalLoader` 文件夹里，重启软件即可勾选。

## 7. 模拟考核题（第 10 章用，限时 3 小时/套）

### 模拟题 A：智能台灯
1. 按键 KEY0 短按切换 LED 开关，长按调节 PWM 亮度（3 档循环）。
2. 按键 KEY1 切换"自动模式"：ADC(PF6) 采样光敏电阻，环境越暗 LED 越亮。
3. OLED 显示当前模式、亮度百分比、光敏电压。
4. 串口每秒上报：`MODE:AUTO,PWM:67%,LIGHT:1.23V`。
5. 亮度档位保存到 EEPROM，断电不丢失。

### 模拟题 B：计数报警器
1. KEY0 外部中断计数（消抖），OLED 显示计数值。
2. 计数达到上限（KEY1 加、KEY2 减）时蜂鸣器响 1 秒、LED 全闪。
3. WKUP 清零计数。
4. 串口可查询/修改上限：`SET LIMIT 20` / `GET LIMIT`。
5. 上限值存 EEPROM。

### 模拟题 C：波形与测量
1. 定时器产生 1 路 1kHz PWM，占空比可通过串口命令 0~100% 调节。
2. 另一路定时器每 500ms 触发 ADC 采样，串口打印电压。
3. OLED 画实时电压曲线（描点连线）。
4. KEY0 暂停/恢复曲线，KEY1 切换 PWM 频率（1k/2k/4kHz）。
5. 当前频率存 EEPROM。

## 9. 给带队人的话（队友可忽略）

- 第 1~3 章让他在主项目副本里练（GPIO/按键引脚已配好）；第 4 章起指导他用官方例程 `.ioc` 转 CMake 生成独立练习工程（CubeMX → Project Manager → Toolchain 选 CMake）。

- 官方例程 main.c 里的 `#include "./LED/led.h"` 对应 `Drivers\BSP\` 下的驱动，教他把驱动文件加进练习工程（或手敲精简版）。
- 第 2 章及以后的文档在他说"给我第 N 章"时再给，一次一章。
