## 1. 工程总览：满配模板 = 官方 33 个例程的"合体"

从官方 `01_LED` 例程出发（结构最简），用 CubeMX 把考核涉及的外设**全部开好**，再把官方 BSP 驱动**原样搬进** `Appli/User/BSP/`（本工程 CMake 会自动递归编译 `User/` 下所有 .c 并自动加头文件路径，**不用改 CMakeLists**）。

### 1.1 满配引脚总表（已排完冲突，直接照配）

| 功能 | 引脚 | CubeMX 配置 |
|---|---|---|
| LED0 / LED1 | PG10 / PE10 | GPIO_Output，初始低 |
| 外接 LED2 / LED3 | PA3 / PB14 | GPIO_Output（面包板接灯+220Ω） |
| 蜂鸣器 | PD3 | GPIO_Output，初始低 |
| 按键 ×4 | PC13 / PC6 / PD1 / PG11 | GPIO_Input + **GPIO_EXTI**：WKUP(PC13) 上拉+上升沿；KEY0/1/2 上拉+下降沿；都开 NVIC |
| 串口 USART1 | PE5(TX) / PE6(RX) | 异步 115200-8-N-1，**开 NVIC 接收中断** |
| 基本定时器 TIM6 | — | 内部时钟，PSC=399、ARR=999（1ms 中断），开 NVIC |
| PWM TIM3_CH1 | PC6 | PWM Generation CH1，PSC=399, ARR=999（→1kHz） |
| ADC | PF6 | ADC1_INP15，单端，轮询即可 |
| EEPROM | PE13 / PE14 | I2C4，标准 100kHz，7 位地址 |
| OLED（软件 SPI，**已改线避开冲突**） | RST=PQ2 / CS=PB8 / RS=PG14 / SCLK=PF9 / SDIN=PF8 | 5 个全配 GPIO_Output，初始高 |

> **为什么 OLED 要改线？** 官方 OLED 引脚里 RS=PE13（撞上 I2C4 的 EEPROM）、SDIN=PE6（撞上串口 RX）。OLED 是软件模拟 SPI，**引脚随便换**——改 `oled.h` 里 5 个宏即可（第 2.4 节有现成改法）。改完 OLED 用杜邦线接到新引脚。
> ⚠️ PF8/PF9/PG14 只是候选，**接线前对照板子排针丝印确认这 5 个脚真的引出来了**，不行就换同排针上的其他空脚（同步改宏）。
> ⚠️ PC6 = KEY0 = TIM3_CH1：用 PWM 时 KEY0 别当按键用。

### 1.2 CubeMX 生成注意事项（N6 特有，做错直接变砖/没反应）

1. Toolchain 选 **CMake**（和我们主项目一致）；
2. 生成后目录里有 `Appli/`，VS Code 打开**整个生成目录**；
3. 编译：`cmake --preset Debug` → `cmake --build --preset Debug`；
4. 烧录：CubeProgrammer + 外部 loader（`MX25UM25645G_ATK-CNN647B_ExtMemLoader.stldr`），**只烧 Appli，不勾 Mass Erase**；
5. 每个引脚 CubeMX 会自动写好 `HAL_GPIO_ConfigPinAttributes(...)`（N6 安全属性），不要删；
6. **时钟树一页都别动**（N6 应用工程不配时钟，由 FSBL 固定：CPU 600MHz、总线 200MHz、定时器 400MHz）——详见《50_保姆级全流程手册》时钟专题。

## 2. 驱动移植清单（照表复制，零改动或极少改动）

源：`D:\BaiduNetdiskDownload\Software_Package\Drivers\BSP\`
目标：模板工程 `Appli/User/BSP/`（建同样结构的文件夹）

| 复制内容 | 依赖 | 需要改什么 |
|---|---|---|
| `LED/led.c + led.h` | 无 | 不用改（引脚与本板一致） |
| `BEEP/beep.c + beep.h` | 无 | 不用改（PD3） |
| `KEY/key.c + key.h` | 无 | 不用改（key_init 是空的，GPIO 靠 CubeMX） |

| `BTIM/btim.c + btim.h` | `extern htim6` | 不用改 |
| `GTIM/gtim.c + gtim.h` | `extern htim3` | 不用改 |

### 2.1 复制后的自检（每个驱动 2 分钟，考前全过一遍）


## 3. 应用层框架（考场就往里填）

在 `Appli/User/` 下建 `app.c / app.h`，main 的 while(1) 里只调一个函数：

```c
/* main.c USER CODE BEGIN WHILE */
app_loop();
```

### 3.1 app.c 骨架（背！所有题都从这个架子长出来）

```c
#include "app.h"

/* ---------- 全局状态 ---------- */
static uint32_t tick = 0;          /* 50ms 软件节拍 */
uint8_t  key_val = 0;              /* 按键值 */
volatile uint8_t key0_exti = 0;    /* 中断标志 */

/* ---------- 串口接收 ---------- */
extern uint8_t  g_uart_rx_buf[UART_REC_LEN];
extern uint16_t g_uart_rx_sta;

void app_loop(void)
{
    tick += 50;

    /* 1. 按键（50ms 扫一次） */
    key_val = key_scan(0);

    /* 2. 中断标志处理 */
    if (key0_exti) { key0_exti = 0; /* 干活 */ }

    /* 3. 串口命令（收到一整行） */
    if (g_uart_rx_sta & 0x8000) { app_uart_cmd(); g_uart_rx_sta = 0; }

    /* 4. 周期任务（分频） */
    if (tick % 200 == 0)  app_task_200ms();   /* 显示刷新 */
    if (tick % 1000 == 0) app_task_1s();      /* 上报 */

    HAL_Delay(50);
}
```

**为什么这样写：** HAL_Delay(50) 保证按键 20 次/秒扫描不卡手；其他任务用 `tick % N` 分频，互不阻塞——这是考场上一切"又要闪灯又要扫键又要收发"问题的统一答案。

## 4. 应用层"答案"速背（按考核点逐块给）

### 4.1 LED / 蜂鸣器（30 秒能写出来）

```c
LED0_TOGGLE();  LED1(1);  BEEP(1);
/* 蜂鸣器"哔"一声 */
#define BEEP_ONCE(ms)  do{ BEEP(1); HAL_Delay(ms); BEEP(0); }while(0)
```

### 4.2 按键（轮询 + 消抖，已封装在 key_scan）

```c
switch (key_scan(0)) {
    case KEY0_PRES: /* KEY0 */  break;
    case KEY1_PRES: /* KEY1 */  break;
    case KEY2_PRES: /* KEY2 */  break;
    case WKUP_PRES: /* WKUP */  break;
}
/* 长按：按下时记 start=HAL_GetTick()，循环里判断仍按着 && 超过2000ms */
```

### 4.3 外部中断（中断里只置标志）

```c
volatile uint8_t key0_exti = 0, key1_exti = 0, key2_exti = 0, wkup_exti = 0;
void HAL_GPIO_EXTI_Falling_Callback(uint16_t GPIO_Pin)   /* KEY0/1/2 用 Falling */
{
    if (GPIO_Pin == GPIO_PIN_6)  key0_exti = 1;
    if (GPIO_Pin == GPIO_PIN_1)  key1_exti = 1;
    if (GPIO_Pin == GPIO_PIN_11) key2_exti = 1;
}
void HAL_GPIO_EXTI_Rising_Callback(uint16_t GPIO_Pin)    /* WKUP 用 Rising */
{
    if (GPIO_Pin == GPIO_PIN_13) wkup_exti = 1;
}
/* 消抖：回调里 if (HAL_GetTick()-last < 50) return; last=HAL_GetTick(); */
```

### 4.4 串口命令解析（万能模板，背！）

```c
void app_uart_cmd(void)
{
    char *buf = (char *)g_uart_rx_buf;

    if      (!strncmp(buf, "LED0 ON",  7)) { LED0(1); printf("OK\r\n"); }
    else if (!strncmp(buf, "LED0 OFF", 8)) { LED0(0); printf("OK\r\n"); }
    else if (!strncmp(buf, "BEEP",     4)) { BEEP_ONCE(200); printf("OK\r\n"); }
    else if (!strncmp(buf, "GET",      3)) { app_report(); }
    else if (!strncmp(buf, "SET TH",   6)) { float v; if (sscanf(buf+7, "%f", &v)==1) { th=v; printf("OK\r\n"); } else printf("ERR\r\n"); }
    else    printf("ERR\r\n");

    memset(g_uart_rx_buf, 0, UART_REC_LEN);   /* 清空 */
}
```

> uart.c 的中断接收逻辑（收满一行置 0x8000）官方已写好，考场不用碰。

### 4.5 定时器（1ms 系统节拍 / 精确定时）

```c
/* main: btim_tim6_int_init(999, 399);  // 1ms 一次中断（400MHz/400/1000）*/
volatile uint32_t g_ms = 0;
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *h)
{
    if (h->Instance == TIM6) g_ms++;
}
/* 用法：uint32_t t0=g_ms;  ...  if (g_ms-t0 >= 500) { 到点了 } */
```

### 4.6 PWM（频率/占空比可调，背！）

```c
/* 占空比 duty%： */
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, (999+1)*duty/100 - 1);
/* 改频率 f Hz（PSC 固定 399 → 计数 1MHz）： */
uint32_t arr = 1000000 / f - 1;
__HAL_TIM_SET_AUTORELOAD(&htim3, arr);
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, (arr+1)*duty/100 - 1);  /* 改ARR必须同步改CCR! */
```

### 4.7 ADC（读电压 + 换算 + 滤波，背！）

```c
uint32_t raw  = adc_get_result_average(15, 10);   /* 通道15(PF6)，10次平均 */
float    volt = raw * 3.3f / 4095.0f;
printf("V=%d.%02dV\r\n", (int)volt, (int)(volt*100)%100);  /* 不依赖 float printf */
```

### 4.9 EEPROM 参数掉电保存（模板，背！）

```c
#define EE_MAGIC_ADDR  0
#define EE_DATA_ADDR   1
#define EE_MAGIC_VAL   0xA5

void param_save(void)   /* 结构体整体写 */
{
    uint8_t magic = EE_MAGIC_VAL;
    eeprom_write(EE_MAGIC_ADDR, &magic, 1);
    eeprom_write(EE_DATA_ADDR, (uint8_t *)&param, sizeof(param));  /* param 是全局结构体 */
}

void param_load(void)   /* 上电读：魔数不对→用默认值 */
{
    uint8_t magic = 0;
    eeprom_read(EE_MAGIC_ADDR, &magic, 1);
    if (magic == EE_MAGIC_VAL)
        eeprom_read(EE_DATA_ADDR, (uint8_t *)&param, sizeof(param));
    else
        param_save();               /* 第一次用：写入默认值 */
}
```
