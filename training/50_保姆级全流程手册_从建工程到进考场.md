# A 章 · 时钟树专题（N647，最大的坑，先看这个！）

## A.1 一句话结论

**N647 的应用工程（Appli）不配置时钟。时钟由 FSBL（已烧在板子里的启动程序）固定好了，你只管写代码，CubeMX 里的时钟页一个像素都不要碰。**

证据：官方例程 `01_LED\Appli\Core\Src\main.c` 的 `main()` 里只有 `HAL_Init()`，**没有 `SystemClock_Config()`**——和普通 STM32 工程最大的区别就在这里。

## A.2 板上实际时钟（从官方 FSBL 源码实锤，背前三个数就行）

```
HSI(64MHz) → PLL1(M=4, N=75) = 1200MHz
    ├─ IC1 ÷2 = 600MHz → CPU 主频
    └─ IC2/IC6/IC11   → 系统总线 → AHB ÷2 = 200MHz
                                      ├─ APB1/2/4/5 = 200MHz（USART、I2C、ADC 内核时钟）
                                      └─ 定时器时钟 = APB×2 = 400MHz（TIM 全部！）
```

| 要背的数字 | 值 | 用在哪 |
|---|---|---|
| 定时器时钟 | **400MHz** | 算 PSC/ARR（PSC=399 → 1MHz 计数） |
| 串口/I2C/ADC 时钟 | 200MHz | HAL 自动处理，不用算 |
| CPU 主频 | 600MHz | 知道就行 |

## A.3 定时器速算表（400MHz 基准，考场直接查）

| 需求 | PSC | ARR | 说明 |
|---|---|---|---|
| 1MHz 计数基准 | 399 | — | 官方例程约定（`gtim_timx_pwm_chy_init(499,399)`=2kHz 就是这么来的） |
| PWM 1kHz | 399 | 999 | 呼吸灯、蜂鸣器 |
| PWM 2kHz | 399 | 499 | |
| PWM 任意频率 f | 399 | 1000000/f − 1 | 公式 |
| TIM6 中断 1ms | 399 | 999 | |
| TIM6 中断 100ms | 399 | 99999 | |

> ⚠️ 经典错误：按普通 STM32（72M/200M）的思维写 PSC=199 → 所有定时快 2 倍，闪烁频率、波特率式延时全错还不容易发现。**记住：这块板子 PSC 写 399。**

## A.4 时钟相关作死行为与症状对照

| 作死行为 | 症状 | 抢救 |
|---|---|---|
| CubeMX 里改了 RCC/时钟页并重新生成 | 复位后板子完全无反应 | 用官方 `01_LED appli.hex` 烧录验证硬件；不行再烧 `fsbl.hex` |
| 动了 XSPI1/XSPI2 配置 | 同上（程序存在外部 Flash，时序错了就读不出代码） | 同上 |
| 改了 USART1 时钟源（CLKP→别的） | 串口打印乱码 | CubeMX 里 USART1 时钟选回默认 CLKP(200MHz) |
| PSC 按 200MHz 算 | 定时/PWM 频率差 2 倍 | PSC 改回 399 |
| 在 Appli 里自己加了 SystemClock_Config | 行为不可预测，可能死机 | 删掉，应用工程不需要它 |

**总原则：时钟、XSPI、RIF 三类配置 = 碰都不要碰。**

# B 章 · 考前全流程（半天，一次做对）

## B.1 第 1 步：复制官方例程当自己工程的种子（5 分钟）

1. 复制 `D:\BaiduNetdiskDownload\Software_Package\Projects\01_LED` 整个文件夹到自己的目录，改名 `ExamTemplate`。
2. 双击打开里面的 `01_LED.ioc`（用 STM32CubeMX）。

## B.2 第 2 步：CubeMX 里加外设（30 分钟，对照《40》文档 1.1 表）

逐个来（每加一个点一下左侧对应外设）：

1. **GPIO 输出**：点 Pinout 图上的 PA3、PB14、PD3（蜂鸣器）→ 选 `GPIO_Output`（PG10、PE10 例程已配好）。
2. **按键+EXTI**：PC13 → `GPIO_EXTI13`；PC6 → `GPIO_EXTI6`；PD1 → `GPIO_EXTI1`；PG11 → `GPIO_EXTI11`。
   然后左侧 `GPIO` 标签页里逐个点这 4 个脚：PC13 设 Pull-up + Rising edge；其余三个 Pull-up + Falling edge。
3. **NVIC**：左侧 `NVIC` 标签页勾上 `EXTI1/6/11/13` 四个中断。
4. **USART1**：左侧 Connectivity → USART1 → Mode 选 Asynchronous → PE5=TX、PE6=RX → 115200 → `NVIC` 勾 `USART1 global interrupt`。
5. **TIM6**：左侧 Timers → TIM6 → 勾 Activated → PSC=399、ARR=999 → NVIC 勾中断。
6. **TIM3**：Timers → TIM3 → Clock Source 选 Internal → Channel1 选 `PWM Generation CH1`（PC6 自动变绿）→ PSC=399、ARR=999、Pulse=500。
7. **ADC1**：Analog → ADC1 → 勾 INP15（PF6 自动变绿），其余默认。
8. **I2C4**：Connectivity → I2C4 → 选 I2C → PE13=SCL、PE14=SDA，100kHz。
9. **OLED 脚**：PQ2、PB8、PG14、PF9、PF8 → 全选 `GPIO_Output`。

**全程不要点：RCC、XSPI、RIF、Clock Configuration 页的任何东西（见 A 章）。**

## B.3 第 3 步：生成 + 搬驱动（20 分钟）

1. CubeMX → Project Manager → Toolchain/IDE 选 **CMake** → Generate Code。
2. VS Code 打开生成的工程文件夹。
3. 按《40》文档第 2 章表格，把官方 `Drivers\BSP\` 下 10 个驱动文件夹拷进 `Appli\User\BSP\`。
4. 改 `oled.h` 的 5 个引脚宏（《40》文档 2.4 节，现成）。
5. `main.c` 的 USER CODE BEGIN 2 里加初始化（《40》文档 2.3 节，现成）。

## B.4 第 4 步：编译 + 烧录 + 自检（30 分钟）

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

CubeProgrammer（选 stldr、不勾 Mass Erase）烧 `Appli/build/*.elf` → 复位。
跑《40》文档 2.1 节的 8 项自检，**全绿才算模板建成**。任何一项不绿：先烧对应官方例程 hex 判断软硬件问题。

## B.5 第 5 步：写入保底程序 + 备份（30 分钟）

1. 把 C 章的保底程序敲进 app.c，编译烧录，全流程演示一遍。
2. 工程文件夹压缩备份 ×2（U盘 + 网盘以外的本地盘），编译好的 elf 单独再备份一份。

# C 章 · 保底程序：按键翻页演示（及格保险，带队人版）

> 定位：烧进板子就有分——LED、按键、蜂鸣器、OLED 显示、串口通信、ADC 全露面。
> KEY0 上翻 / KEY1 下翻，3 个页面循环；LED0 心跳；串口每秒上报 + 收命令。

```c
/* app.c —— 保底及格程序（按键翻页） */
#include "main.h"
#include "led.h"
#include "beep.h"
#include "key.h"
#include "uart.h"
#include "adc.h"
#include "oled.h"
#include <stdio.h>
#include <string.h>

static uint8_t  page = 0;      /* 当前页 0~2 */
static uint32_t tick = 0;
static uint32_t key_cnt = 0;   /* 按键总计数 */

extern uint8_t  g_uart_rx_buf[UART_REC_LEN];
extern uint16_t g_uart_rx_sta;

static void show_page(void)
{
    char s[24];
    uint32_t raw = adc_get_result_average(15, 10);

    oled_clear();
    sprintf(s, "PAGE %d/3", page + 1);
    oled_show_string(0, 0, s, 16);

    if (page == 0) {                                     /* 页1：输出演示 */
        oled_show_string(0, 2, "LED0 BLINKING", 16);
        oled_show_string(0, 4, "K2:BEEP K3:LED1", 16);
    } else if (page == 1) {                              /* 页2：输入演示 */
        sprintf(s, "KEY CNT:%lu", key_cnt);
        oled_show_string(0, 2, s, 16);
        sprintf(s, "ADC:%lu.%02luV", raw*33/4095/10, (raw*33/4095)%10*10 + (raw*330/4095)%10);
        oled_show_string(0, 4, s, 16);
    } else {                                             /* 页3：通信演示 */
        oled_show_string(0, 2, "UART:115200", 16);
        oled_show_string(0, 4, "CMD:BEEP/LED1", 16);
    }
    oled_refresh_gram();
}

void app_loop(void)
{
    uint8_t k;
    tick += 50;

    k = key_scan(0);
    if (k == KEY0_PRES) { page = (page + 2) % 3; key_cnt++; show_page(); }
    if (k == KEY1_PRES) { page = (page + 1) % 3; key_cnt++; show_page(); }
    if (k == KEY2_PRES) { key_cnt++; BEEP(1); HAL_Delay(100); BEEP(0); }
    if (k == WKUP_PRES) { key_cnt++; LED1_TOGGLE(); }

    if (g_uart_rx_sta & 0x8000) {                        /* 串口命令 */
        g_uart_rx_sta = 0;
        if (!strncmp((char*)g_uart_rx_buf, "BEEP", 4)) { BEEP(1); HAL_Delay(200); BEEP(0); printf("OK\r\n"); }
        else if (!strncmp((char*)g_uart_rx_buf, "LED1", 4)) { LED1_TOGGLE(); printf("OK\r\n"); }
        else printf("ERR\r\n");
        memset(g_uart_rx_buf, 0, UART_REC_LEN);
    }

    if (tick % 500 == 0)  LED0_TOGGLE();                 /* 心跳 */
    if (tick % 2000 == 0) printf("RUN %lus PAGE:%d CNT:%lu\r\n", tick/1000, page+1, key_cnt);

    HAL_Delay(50);
}
```

main.c 的 USER CODE BEGIN 2 里：`uart_init(115200); adc_init(); oled_init(); show_page(); printf("BOOT OK\r\n");`
（show_page 声明放 app.h 或 main.c 顶部 extern。）

**演示话术（验收时说）：**"这是按键翻页演示：KEY0/KEY1 翻页；页面 1 演示 LED 和蜂鸣器输出；页面 2 演示按键计数和 ADC 电压采集；页面 3 是串口通信，电脑发 BEEP/LED1 可以控制板子。"——一段话覆盖 6 个考核点。

# D 章 · 考场当天傀儡流程（照表执行）

| 时间 | 动作 |
|---|---|
| 进场~10min | 接线（板子、ST-LINK、串口、OLED、电位器、面包板 LED）→ CubeProgrammer Connect → 烧保底程序 elf → 复位确认翻页正常 |
| 10~15min | 读题！把题目要求抄成功能点清单，按"会做的/分值高的"排序，标出每项对应《40》第 4 章哪个代码块 |
| 15~90min | 逐项实现：每完成一项 → 编译 → 烧录 → 验证 → 存 backup_vN.elf。顺序建议：显示 → 按键 → 串口 → 采集 → 输出控制 → 存储 |
| 90~100min | 若全部完成：补 EEPROM 掉电保存类加分项；没完成：停手，保已有功能 |
| 100~115min | 回归测试（对照题目逐条打勾）→ 最终版重新烧录 → 断电重上电再验一次 |
| 115~120min | 叫专家验收：按题目顺序演示，边演示边说一句这是什么功能；签字前确认每条都演示过 |

**红线复读机：不碰时钟、不碰 XSPI、不勾 Mass Erase、中断里只置标志、PSC=399。**
