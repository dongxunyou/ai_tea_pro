## 一、题目

用本开发板实现一个"多功能控制器"，由按键和电脑串口共同控制。

### 基础部分（60 分）

1. **LED 控制（15 分）**：LED0(PG10) 每秒闪烁一次（亮 500ms 灭 500ms）；LED1(PE10) 熄灭。
2. **按键控制（20 分）**：
   - 按一下 KEY0(PC6)：LED1 翻转（亮变灭、灭变亮）；
   - 按一下 KEY1(PD1)：蜂鸣器(PD3) 响 200ms；
   - 按键必须消抖，按一下只算一下。
3. **串口上报（15 分）**：每次按键被按下，通过 USART1(PE5/PE6, 115200) 向电脑打印一行，例如：
   ```
   KEY0 PRESSED, LED1=ON
   KEY1 PRESSED, BEEP
   ```
4. **代码规范（10 分）**：引脚用 `#define` 宏定义，按键扫描写成函数，代码写在 USER CODE 保护区内。

### 提高部分（30 分）

5. **外部中断（15 分）**：把 KEY0 改成**外部中断**方式（下降沿触发），中断里计数，主循环里根据计数翻转 LED1（中断里不许直接 HAL_Delay）。
6. **串口命令（15 分）**：电脑通过串口助手发送命令控制板子（以回车结尾）：
   - `LED1 ON` / `LED1 OFF` → 控制 LED1 并回复 `OK`
   - `BEEP` → 蜂鸣器响 200ms 并回复 `OK`
   - 收到不认识的命令回复 `ERROR`

### 挑战部分（10 分，时间够才做）

7. **PWM 呼吸灯（10 分）**：用 TIM3_CH1(PC6) 输出 PWM 驱动外接 LED（或示波器观察），占空比 0%→100%→0% 循环变化，周期约 2 秒。
   （注意：PC6 与 KEY0 复用，做这题时 KEY0 功能可以不管。）

# 解题思路（做完一部分前不许看对应小节！）

## 0. 总体战略（先看这个）

**推荐做题顺序 = 按分值/难度性价比排序：**

```
① GPIO 点灯(15min) → ② 按键轮询(25min) → ③ 串口(30min)
→ ④ EXTI 改造(20min) → ⑤ 串口命令(20min) → 剩余时间检查 + 挑战题
```

**每一大步都遵循同一个节奏：**


## 1. 工程准备（5 分钟）

- 在**自己的练习工程**里做（主项目副本即可：注释掉 RTOS 那 4 行，见第 1 章 1.9 节）。
- 串口部分主项目引脚被占用，需要 USART1(PE5/PE6)：在 `.ioc` 里把 PE5/PE6 配成 USART1_TX/RX，重新生成。**这一步如果搞不定，先用主项目的 USART3(PE1/PD9) 顶着，功能一样，跟考官说明即可。**

## 2. 第 1 题：LED 闪烁

就是第 1 章实操 2，`HAL_GPIO_TogglePin + HAL_Delay(500)`。
**建议顺手写成宏**（第 4 题的"代码规范"分就拿稳了）：

```c
#define LED0_TOGGLE()  HAL_GPIO_TogglePin(GPIOG, GPIO_PIN_10)
#define LED1(x)        HAL_GPIO_WritePin(GPIOE, GPIO_PIN_10, (x)?GPIO_PIN_SET:GPIO_PIN_RESET)
```

## 3. 第 2 题：按键 + 消抖

**思路骨架**（对照官方 `BSP\KEY\key.c` 的 `key_scan`，这是全场最该偷师的函数）：

```c
uint8_t key_scan(void)
{
    // 1. 检测到某个键按下（注意：WKUP按下=1，KEY0/1/2按下=0）
    // 2. HAL_Delay(10) 消抖
    // 3. 再读一次，还是按下 → 确认，返回键值
    // 4. 等待松手（while 读引脚），防止按住不放连发
    // 5. 没按下返回 0
}
```

主循环：

```c
while (1) {
    key = key_scan();        // 扫描按键
    switch (key) {           // 有键按下才进分支
        case KEY0_PRES: LED1 翻转 + printf; break;
        case KEY1_PRES: 蜂鸣器响200ms + printf; break;
    }
    HAL_GPIO_TogglePin(GPIOG, GPIO_PIN_10);   // LED0 心跳
    HAL_Delay(500);
}
```

**坑：** `HAL_Delay(500)` 会让按键扫描变卡（500ms 才扫一次）。**改用 `HAL_Delay(50)` 扫描 + 计数器凑够 500ms 再翻转 LED0**，或者先忍了，提高部分做完再优化。考试时可以这样：

```c
static uint16_t cnt = 0;
HAL_Delay(50);
if (++cnt >= 10) { cnt = 0; LED0_TOGGLE(); }   // 50ms*10=500ms
key = key_scan(); ...
```

## 4. 第 3 题：串口上报

照官方 `05_Serial` 例程 + `BSP\UART\uart.c`：

1. CubeMX 开 USART1：Asynchronous，115200-8-N-1，**勾上 NVIC 中断**；
2. 重定向 printf（在 USER CODE 区加）：

```c
int __io_putchar(int ch)   // 或 int fputc(int ch, FILE *f)，编译器不认就换这个
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
    return ch;
}
```

3. `printf("KEY0 PRESSED\r\n");` 即可。串口助手选 115200，看不到字先检查 TX/RX 是否接反、波特率。

## 5. 第 5 题：EXTI 改造

对照官方 `04_Button_EXTI` + `BSP\EXTI\exti.c`：

1. CubeMX：PC6 改成 `GPIO_EXTI6`，下拉触发（按键按下=低电平 → **下降沿**），开 `EXTI6_IRQn` 中断；
2. 中断回调函数（写在 USER CODE 区）：

```c
void HAL_GPIO_EXTI_Falling_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_6) { key0_flag = 1; }   // 只置标志！
}
```

3. 主循环检查 `key0_flag`，置位了就处理 + 清零。
**铁律：中断函数里只能置标志位，禁止 printf / HAL_Delay / 干重活。** 中断里的抖动问题：置标志前可记录 `HAL_GetTick()`，两次中断间隔 <50ms 就忽略。

## 6. 第 6 题：串口命令解析

官方 `uart.c` 的接收逻辑：中断每次收 1 字节 → 存 buffer → 收到 `\n`(0x0A) 置"接收完成"标志。

```c
// 中断回调（官方例程里已写好框架）
void HAL_UART_RxCpltCallback(...) { ... g_uart_rx_sta |= 0x8000; ... }

// 主循环
if (接收完成) {
    if (strstr(buf, "LED1 ON"))  { LED1(1); printf("OK\r\n"); }
    else if (strstr(buf, "LED1 OFF")) { LED1(0); printf("OK\r\n"); }
    else if (strstr(buf, "BEEP")) { ... }
    else printf("ERROR\r\n");
    清标志和buffer; 重新开启接收中断;
}
```

**坑：** 每次接收完成要重新调 `HAL_UART_Receive_IT()`；比较字符串用 `strstr` 比 `strcmp` 省事（串口助手可能带 `\r`）。

## 7. 第 7 题（挑战）：PWM

对照 `09_General_Purpose_Timer\092_PWM` + `BSP\GTIM\gtim.c`：

1. CubeMX：TIM3 → CH1 选 PWM Generation，PC6 自动占用；设 PSC/ARR 定频率；
2. 启动：`HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);`
3. 调占空比：`__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 值);`
4. 呼吸：变量 `duty` 每 10ms 加/减 1，到头反向。

**PWM 频率公式：** `频率 = 定时器时钟 / ((PSC+1) × (ARR+1))`，人眼要不闪得 ≥100Hz，建议 1kHz。
