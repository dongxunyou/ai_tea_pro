## 1.1 先搞清楚这块板子的 3 个特殊之处（1 分钟）

1. **它没有内部 Flash。** 程序存在板子上的外部 Flash 芯片里。
2. **上电先跑 FSBL**（一小段启动程序，已经在板子里了），再由 FSBL 跳转到我们写的程序（叫 **Appli**）。
3. **烧录铁律：只烧 Appli，永远不点"全片擦除 / Mass Erase"。** 万一擦了，板子变砖，用官方包里的 `FSBL\...\Binary\fsbl.hex` 恢复（找带队人）。

└── CMakeLists.txt            ← 构建脚本（不用动）

**重要概念 · USER CODE 保护区：**

```c
/* USER CODE BEGIN 2 */
（写在这里的代码会被保留）
/* USER CODE END 2 */
```

**所有手写代码必须写在 BEGIN 和 END 之间！** 否则用 CubeMX 重新生成时会被删掉。这是新手最常见的悲剧。

## 1.10 GPIO 是什么（原理课，15 分钟）

GPIO = 通用输入输出口。引脚可配置成**输出**（往外送高低电平）或**输入**（读外面电平）。

- **高电平（1）** ≈ 3.3V；**低电平（0）** ≈ 0V。本板 LED 高电平点亮。

### 必懂的 4 个名词

| 名词 | 意思 | 什么时候用 |
|---|---|---|
| 推挽输出 (Push-Pull) | 能主动输出高也能输出低 | LED、蜂鸣器，99% 输出场景 |
| 开漏输出 (Open-Drain) | 只能主动拉低，高靠外部上拉 | I2C 总线（第 8 章遇到） |
| 上拉/下拉输入 | 内部接电阻到 VCC/GND，防止悬空乱跳 | 按键输入必用（第 2 章） |
| 速度 (Speed) | 引脚翻转能力 | 普通 IO 选 Low 就行 |

本工程的 `MX_GPIO_Init()`（在 `gpio.c`）已经把 **PG10、PE10、PD3** 等配置成推挽输出，**直接用，不用自己配**。

## 1.11 必背的 5 个函数（本章全部武器）

```c
// ① 写引脚：SET=高电平，RESET=低电平
HAL_GPIO_WritePin(GPIOG, GPIO_PIN_10, GPIO_PIN_SET);

// ② 翻转引脚
HAL_GPIO_TogglePin(GPIOG, GPIO_PIN_10);

// ③ 读引脚（第2章用）
HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13);

// ④ 延时（毫秒）
HAL_Delay(500);

// ⑤ 毫秒计时（开机至今的毫秒数，第2章用）
HAL_GetTick();
```

引脚命名规律：`GPIOG + GPIO_PIN_10` = G 口 10 号脚 = PG10。

## 1.12 实操 1：点亮 LED0（你的第一行 STM32 代码）

在 `main.c` 找到：

```c
  /* USER CODE BEGIN WHILE */
  while (1) {
```

敲入（写在 BEGIN WHILE 下面、while 上面）：

```c
  /* USER CODE BEGIN WHILE */
  HAL_GPIO_WritePin(GPIOG, GPIO_PIN_10, GPIO_PIN_SET);   // LED0 亮
  while (1) {
```

编译 → 烧录 → 复位。**LED0 亮了 → 第一个程序完成。**

> 顺手实验：改成 `GPIOE, GPIO_PIN_10`（LED1）；改成 `GPIO_PIN_RESET`（灭）。

## 1.13 实操 2：LED0 闪烁（每 500 毫秒变一次）

删掉刚才那行，在 `while (1)` **里面**敲：

```c
  /* USER CODE BEGIN WHILE */
  while (1) {
      HAL_GPIO_TogglePin(GPIOG, GPIO_PIN_10);   // 翻转 LED0
      HAL_Delay(500);                           // 等 500ms
  /* USER CODE END WHILE */
```

## 1.14 实操 3：双灯交替闪 + 蜂鸣器（本章结业项目）

LED0 亮时 LED1 灭、蜂鸣器短响；然后反过来，循环。先自己写 5 分钟再看：

```c
  /* USER CODE BEGIN WHILE */
  while (1) {
      HAL_GPIO_WritePin(GPIOG, GPIO_PIN_10, GPIO_PIN_SET);    // LED0 亮
      HAL_GPIO_WritePin(GPIOE, GPIO_PIN_10, GPIO_PIN_RESET);  // LED1 灭
      HAL_GPIO_WritePin(GPIOD, GPIO_PIN_3, GPIO_PIN_SET);     // 蜂鸣器响
      HAL_Delay(100);
      HAL_GPIO_WritePin(GPIOD, GPIO_PIN_3, GPIO_PIN_RESET);   // 蜂鸣器停
      HAL_Delay(400);

      HAL_GPIO_WritePin(GPIOG, GPIO_PIN_10, GPIO_PIN_RESET);  // LED0 灭
      HAL_GPIO_WritePin(GPIOE, GPIO_PIN_10, GPIO_PIN_SET);    // LED1 亮
      HAL_GPIO_WritePin(GPIOD, GPIO_PIN_3, GPIO_PIN_SET);
      HAL_Delay(100);
      HAL_GPIO_WritePin(GPIOD, GPIO_PIN_3, GPIO_PIN_RESET);
      HAL_Delay(400);
  /* USER CODE END WHILE */
```

> 注意：蜂鸣器常响很吵，所以只响 100ms。试试把 `GPIOD, GPIO_PIN_3` 那几行删掉，对比有无蜂鸣器的效果。

## 1.16 常见错误排查表（收藏！）

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| `cmake 不是内部或外部命令` | 环境没装好 / 终端没重启 | 重开终端；不行找带队人 |
| 编译红色 error | 代码敲错 | 看报错行号，多半是少分号/括号 |
| CubeProgrammer 连不上 | 线/驱动/被占用 | 换 USB 口；关掉 VS Code 调试会话 |
| 烧录报 loader 错误 | 没选外部 loader | 回 1.5 节第 1、4 步 |
| 烧录成功但没反应 | 没复位 / 代码位置写错 | 按复位；检查代码在 USER CODE 区内 |
| 灯不亮但程序在跑 | 引脚写错 | 对照 1.2 节引脚表 |
| 改完代码现象没变 | 忘了重新编译/烧录 | 编译→烧录→复位，三步缺一不可 |
| 点了 Mass Erase 板子死了 | FSBL 被擦 | 用官方 `fsbl.hex` 恢复，找带队人 |
